# GMT Associates Website V4

Premium refinement of the GMT Associates public website.

## V4 changes
- Keeps the polished original GMT identity and logo direction.
- Tightens the desktop/mobile header and increases logo presence.
- Changes primary conversion language to **Start a Project**.
- Changes hero positioning line to **Commercial Construction • Self-Perform Expertise**.
- Emphasizes self-perform Demolition / Concrete / Carpentry / Structural capabilities above the fold.
- Adds restrained scroll-reveal and project hover interaction.
- Makes Projects the centerpiece of the site with dedicated case-study pages.
- Adds case studies for 100 Middlesex Center Blvd, Hamilton Phase II, D-BAT, 2301 Cherry Street, and 2303 Center Square.
- Maintains conservative wording: project scope is limited to material supported by GMT project records; representative imagery is identified where appropriate.

## Upload to GitHub
Upload the **contents of this folder** to the root of the `gmt-associates-website` repository. Do not upload the enclosing `gmt-associates-site-v4` folder.

Suggested commit message: `GMT Website V4 - premium project experience update`

Keep the GitHub Pages preview in place until desktop and mobile QA is complete. Connect `gmtassociates.com` only after approval.
